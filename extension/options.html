Search Tabs for Zammad

Get started

Sign in to your Zammad workspace and open this extension's toolbar panel. Choose Allow access and enable, then approve your browser's site access request. Search tabs will start automatically. If access is already allowed, choose Enable on this site.

The global search opens another tab. The search field in the results area and the filter builder edit the current tab.

Hover over a search tab and click the pencil to name it. Leave the name empty to show the query again. Drag tabs to reorder them, or focus a tab and press Alt + Up or Alt + Down.

Private windows

Open the extension's details in your browser and turn on Allow in incognito. Then sign in to Zammad in a private window and enable the extension there.

By default, private queries, tab names and tab order are kept in memory, separately from regular windows, and removed when the last private window closes. Enable the site again for each new private session.

When enabled, private windows use the regular profile's searches for the same Zammad address and account. Changes remain after private windows close. Turning this off does not remove data already saved in the regular profile. Temporary searches remain separate until the private session ends.

    Your data

    Search text is saved locally in this browser profile, grouped by the Zammad address and account ID. Queries can contain personal or confidential information. The extension also reads your locale and the state, priority and group labels needed by the filter builder.

    The extension sends no data to the developer or third parties. It has no analytics, advertising, cloud sync or remote code.
